# Lakshya Groups

Marketing site + client portal for lakshyagroups.in. Built with Next.js 16 (App Router, static export), Tailwind CSS 4, Supabase, GSAP/Framer Motion.

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
```

Copy `.env.example` to `.env.local` and fill in Supabase / SMTP / FTP values before running features that need them.

## Project layout

```
src/components/     UI, sections, portal widgets
src/lib/            Supabase clients, helpers, site config
src/data/           Blog posts, case studies
public/             Static assets served by Next
scripts/            Active dev/deploy/maintenance scripts
  checks/           One-off browser/QA checks (Playwright, audits)
  legacy/           Old Python FTP/DB helpers kept for reference

documentation/      Product/design/SEO docs and site audits
docs/               Published GitHub Pages artifact (see below)
archive/legacy-server/  Old start.bat / server.js / PM2 launcher
backups/            Local-only DB dumps and scratch artifacts (gitignored)
out/                Next build output, FTP-deploy source (gitignored)
```

### `docs/` — GitHub Pages artifact

`docs/` holds the **published GitHub Pages build** (`ash456rt.github.io/lakshya-deploy`). It is generated by `next build`; do not edit it by hand. It lives in `docs/` because GitHub Pages can only serve from a branch root or `/docs`.

**Required repo setting:** Settings → Pages → Source = *Deploy from a branch*, branch `master`, folder `/docs`.

The real source lives in `src/` and `public/`. Hostinger production is deployed from `out/` via `npm run deploy:ftp`.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Local dev server |
| `npm run build` | Static export into `out/` |
| `npm run lint` | ESLint |
| `npm run deploy:ftp` | Build, then upload `out/` to Hostinger over FTP (resumable, then smoke-tests live routes) |
| `npm run db:setup` | Apply Supabase schema |
| `npm run db:cleanup` | Remove demo data |
| `npm run monitor` | Uptime/health monitor |

Deploy credentials come from `.env.local` (`DEPLOY_FTP_*`); see `scripts/deploy-ftp.mjs` for the full list.
